# StudentFlow

 StudentFlow is a student task management and productivity web application designed to help students organize their academic tasks, deadlines, priorities, and study plans in one place.

 ## Features

 - Add, edit, and delete tasks
- Mark tasks as completed or pending
- Set task priorities
- Add subjects and descriptions
- Set deadlines and estimated time
- Search and filter tasks
- Dashboard with task and productivity statistics
- Calendar for managing deadlines
- Smart Planner for organizing work
- Notifications for upcoming tasks
- Student profile and settings
- Sakura-themed landing page
- Local storage for browser-based data persistence
- Supabase database integration

 ## Technologies Used

 - React.js
- Vite
- JavaScript
- CSS
- Supabase
- Git
- GitHub
- Vercel

 ## Getting Started

 Install the project dependencies:

```
npm install
```

 Start the development server:

```
npm run dev
```

 The application will then be available through the local development URL provided by Vite.

 ## Database

 Supabase is used as the backend database service. The project contains a `tasks` table for storing task information.
